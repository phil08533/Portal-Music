# Portal Music

Free, royalty-free music for creators — [portal-music.com](https://portal-music.com).

## How it fits together

| Piece | Where it lives |
|---|---|
| Website (static HTML/CSS/JS) | This repo, deployed to **GitHub Pages** from `main` (`.github/workflows/pages.yml`) |
| Audio + cover art | **Cloudflare R2** → `https://assets.portal-music.com/` (not in git) |
| Track catalog | `data/music.json`, `data/genres.json`, `data/artists.json` |
| Accounts, favorites, playlists, Pro status | **Firebase** Auth + Firestore (`js/firebase-auth.js`, rules in `firestore.rules`) |
| Pro subscriptions ($3/mo, $20/yr) | **Stripe** Payment Links → Cloudflare Worker (`workers/stripe-pro/`) sets Pro in Firestore |
| Ads | **Monetag** popunder, configured only in `js/app.js` (`AD_ZONES`); never shown to Pro members |
| SEO pages | `tracks/*.html`, `genres/*.html`, `sitemap-tracks.xml` — generated by `npm run seo` |

## Day-to-day

```bash
npm install          # once
npm run admin        # Admin Studio at http://localhost:3030 — upload tracks, edit catalog, manage users & Pro
npm run seo          # rebuild track/genre pages + sitemap after catalog edits
python3 -m http.server 8080   # preview the site at http://localhost:8080
```

See **ADMIN_GUIDE.md** for uploading music, syncing to R2 and managing users,
**workers/stripe-pro/README.md** for the Stripe setup, and **TODO.md** for open owner tasks.

## Files that are never deployed

The Pages workflow strips `admin/`, `scripts/`, `workers/`, docs, `package*.json` and
`firestore.rules` before publishing. `admin/serviceAccountKey.json` is gitignored — never commit it.

## Scripts

| Script | Purpose |
|---|---|
| `scripts/generate-seo-pages.js` | Track/genre pages + sitemap (`npm run seo`) |
| `scripts/update-catalog.js` | Adds new files in `music/` to the catalog (also run by `.github/workflows/update-catalog.yml`) |
| `scripts/migrate-to-r2.js` | One-time: rewrote catalog paths to R2 URLs |
| `scripts/generate-license-pdf.js` | Rebuilds `downloads/portal-music-license.pdf` |
| `scripts/feature-random.js` | Picks random tracks to feature on the homepage |
| `scripts/stamp-assets.js` | Adds `?v=<hash>` to CSS/JS links on deploy so browsers never use stale copies (run by the Pages workflow) |
