🔐 Connect your Firebase project

User management needs a Firebase service account key. It stays on this computer only — it's gitignored and never deployed.

  1. Open Firebase Console → Project Settings → Service accounts
  2. Click Generate new private key → Generate key
  3. Rename the downloaded file to serviceAccountKey.json and move it into the admin/ folder
  4. Stop the studio (Ctrl+C) and run npm run admin again

🎬 Make a video

Pick a track and a clip. You get a ready-to-post MP4 with the cover art, an animated waveform and "free at portal-music.com". Takes a few seconds.

Result

Your video will appear here.

Tips
• Start at the catchiest part (a drop or chorus), not the intro.
• 15–30 s works best for Reels and TikTok.
• For YouTube, choose "Whole track" + Landscape, and paste the caption into the description.
• Videos are also saved in social/reels/ in your Portal-Music folder.

🚀 Deployment & Sync Tools

Perform one-click publishing actions to update SEO pages, sync to Cloudflare R2, and push to GitHub.

1. Regenerate SEO Pages & Sitemap

Rebuilds all 470+ track static pages and genre pages for Google SEO.

2. Sync Assets to Cloudflare R2

When you add new audio files to music/, sync them to your Cloudflare R2 bucket:

aws s3 sync music/ s3://portal-music-assets/music/ --endpoint-url "https://5d2f9b493e0a8358e1b201bd9834c99d.r2.cloudflarestorage.com" --content-type "audio/mpeg" aws s3 sync covers/ s3://portal-music-assets/covers/ --endpoint-url "https://5d2f9b493e0a8358e1b201bd9834c99d.r2.cloudflarestorage.com"
3. Publish to the live site

Edits here only change the files on this computer. After step 1, push them to GitHub (run in a terminal in the Portal-Music folder); the site updates about a minute later:

git add -A && git commit -m "Update catalog" && git push
