🔐 Connect your Firebase project

User management needs a Firebase service account key. It stays on this computer only — it's gitignored and never deployed.

  1. Open Firebase Console → Project Settings → Service accounts
  2. Click Generate new private key → Generate key
  3. Rename the downloaded file to serviceAccountKey.json and move it into the admin/ folder
  4. Stop the studio (Ctrl+C) and run npm run admin again

🏷️ AI Tags

Two AI models listen to every song, calibrated to each other. A tag goes on the site only when both agree (or it's measured, like tempo and length). Tags only one model hears stay hidden (they just help search a little), and vocals/energy/tempo disagreements settle themselves. You only review songs where both models are sure and contradict each other, usually very few. Your decisions always win.

One-time setup: in a terminal in the Portal-Music folder run npm run analyze:setup (installs the free AI tools and downloads the two models, about 2 GB, takes a while). If it says venv is missing, first run sudo apt install python3-venv. Then restart the admin studio.

🚀 Deployment & Sync Tools

        
Perform one-click publishing actions to update SEO pages, sync to Cloudflare R2, and push to GitHub.


        

          

            1. Regenerate SEO Pages & Sitemap
            
Rebuilds all 470+ track static pages and genre pages for Google SEO.

            
          


          

            2. Sync Assets to Cloudflare R2
            
After adding tracks or WAVs, upload the new files to your Cloudflare R2 bucket:

            aws s3 sync music/ s3://portal-music-assets/music/ --endpoint-url "https://5d2f9b493e0a8358e1b201bd9834c99d.r2.cloudflarestorage.com" --exclude "*.wav" --content-type "audio/mpeg"
            aws s3 sync music/ s3://portal-music-assets/music/ --endpoint-url "https://5d2f9b493e0a8358e1b201bd9834c99d.r2.cloudflarestorage.com" --exclude "*" --include "*.wav" --content-type "audio/wav"
            aws s3 sync covers/ s3://portal-music-assets/covers/ --endpoint-url "https://5d2f9b493e0a8358e1b201bd9834c99d.r2.cloudflarestorage.com"
            
          


          

            3. Publish to the live site
            
Edits here only change the files on this computer. After step 1, push them to GitHub (run in a terminal in the Portal-Music folder); the site updates about a minute later:

            git add -A && git commit -m "Update catalog" && git push
